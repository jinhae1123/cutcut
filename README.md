# ✂️ 싹둑싹둑 오리기 놀이

3~5세 유아의 **가위로 선 따라 오리기** 연습 활동지를 단계별로 자동 생성하고 A4로 인쇄하는 웹 도구입니다.  
설치나 서버 없이 `index.html` 하나로 동작합니다.

## 기능
- **5단계 난이도**: 1 짧은 곧은 길 → 2 긴·비스듬한 길 → 3 물결 길 → 4 지그재그·계단 길 → 5 모양 오리기(동그라미·네모·세모·하트·별·꽃·달팽이 길)
- **테마 6종 + 깜짝 테마**: 동물 친구, 탈것, 바닷속, 우주, 공룡, 숲속 곤충
- **나만의 테마 만들기**: `출발이모지 도착이모지 이야기` 형식으로 입력 (브라우저에 저장)
- **재미 요소**: 이야기 미션 문장, 출발 ✂️ → 도착 그림, 다 하면 색칠하는 ☆, '참 잘했어요' 도장 칸, 가위 박사 도전판 + 오려서 쓰는 상장
- **새 모양으로 바꾸기**: 누를 때마다 새로운 선 모양 생성
- 단계 여러 개 × 장수 묶음 인쇄, 점선/실선, 흑백(색칠놀이용) 옵션

## 놀이 활동지 (48종)
- **테마 자르기 16종**: 국수 면, 문어 다리, 빗줄기, 파도, 미용실, 꽃밭, 김밥, 무지개, 사자 갈기, 해파리, 버드나무, 수박, 벼 들판, 털목도리, 산타 수염, 눈썰매 언덕
- **오려 붙이기 17종**: 요리사, 장보기, 어항, 케이크, 피자, 꽃병, 트리, 도시락, 눈사람, 가을 나무, 봄 꽃밭, 바닷가, 냉장고, 옷 입히기, 주차장, 농장, 썰매 태워 주기
- **색칠하고 오리기 15종**: 왕관, 손가락 인형, 퍼즐, 가면, 머리띠, 손목시계, 겨울 장식, 부채, 물고기 낚시, 계절 가랜드, 책갈피, 접어 오리는 나비, 가을 낙엽, 장갑 짝 맞추기, 눈송이 접어 오리기

## 계절별 활동
- 봄🌸 · 여름🍉 · 가을🍂 · 겨울⛄ 필터로 계절 활동만 골라 볼 수 있고, '이 계절 활동 모두 고르기'로 한 번에 세트를 만들 수 있습니다.
- 계절 테마 4종(봄 나들이, 신나는 여름, 풍성한 가을, 하얀 겨울)이 단계별 선 오리기·6단계 그림 오리기·인형·퍼즐에도 쓰입니다.

## 랜덤 뽑기
- 활동 종류·난이도 범위·계절을 정하면 최대 12장을 무작위로 뽑아 줍니다. 다 나오기 전까지 같은 활동은 겹치지 않습니다.

## 사용법
1. 단계(여러 개 가능)와 장수, 테마를 고릅니다.
2. **인쇄하기** → 용지 A4, 배율 100%로 인쇄합니다.

## GitHub Pages로 배포

3. 1~2분 뒤 `https://jinhae1123.github.io/cutcut/` 에서 열립니다.
